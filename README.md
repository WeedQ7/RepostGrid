# Repost Grid — сборка IPA с Windows через GitHub Actions

## Что получится
GitHub Actions соберёт приложение под устройство iPhone и сохранит артефакт `RepostGrid-unsigned.ipa`.
Это **неподписанный** IPA: его нужно подписать своим Apple ID в привычном инструменте (например, Sideloadly). Сам workflow не просит Apple ID и не хранит сертификаты.

## Шаги с Windows
1. Скачай и распакуй ZIP.
2. Войди на https://github.com/ или создай аккаунт.
3. Создай новый репозиторий, например `RepostGrid`.
4. Загрузить в репозиторий все файлы и папку из архива, включая скрытую папку `.github`.
   - Самый простой способ: GitHub → репозиторий → **Add file → Upload files**, перетащи файлы из распакованной папки.
   - Убедись, что `.github/workflows/build-ios.yml` присутствует. Если браузер не показывает скрытую папку, включи отображение скрытых файлов в Проводнике или загрузи через GitHub Desktop.
5. Открой вкладку **Actions** в репозитории. Если появится запрос, нажми **I understand my workflows, go ahead and enable them**.
6. Выбери **Build unsigned iOS IPA** → **Run workflow** → **Run workflow**.
7. Дождись зелёной галочки. Открой завершённый запуск, внизу раздел **Artifacts**, скачай `RepostGrid-unsigned-IPA` и распакуй скачанный ZIP.
8. Внутри будет `RepostGrid-unsigned.ipa`. Импортируй его в свой привычный инструмент подписи и подпиши Apple ID.

## Если сборка упала
Открой Actions → последний запуск → шаг с красным крестом и скопируй лог ошибки. Не публикуй секреты или данные Apple ID.

## Ограничения приложения
- Карточки репостов пока демонстрационные.
- Счётчики считают ручные отметки; они не подтверждают реальное состояние TikTok.
- TikTok открывается через WKWebView. Вход в веб-версию может быть отдельным от официального приложения.
- У TikTok нет документированного публичного API для получения пользовательских репостов и их снятия, поэтому автоматическое удаление пока не реализовано.

## Безопасность и подпись
Не добавляй Apple ID, пароль, код двухфакторной аутентификации, сертификат `.p12` или закрытые ключи в репозиторий/GitHub Actions. Бесплатная персональная подпись обычно ограничена сроком и возможностями; условия зависят от инструмента и способа подписи.
